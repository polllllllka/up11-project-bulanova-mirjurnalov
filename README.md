##  Буланова Полина 3ИП-1-24 «Мир журналов» — приложение для автоматизации продаж журналов.

## Используемые технологии
- **Язык:** Python 3.12.6
- **GUI:** PySide6 6.12.0
- **СУБД:** PostgreSQL 18.6
- **Драйвер БД:** psycopg2-binary 2.9.13

## Назначение и основные функции
Приложение автоматизирует продажи журналов. Функции:
- Каталог товаров (изображение, цена, скидка);
- Авторизация по логину;
- Фильтрация, сортировка, поиск;
- Оформление заказа;
- Управление заказами (Менеджер, Администратор).

## Порядок подготовки БД и запуска
1. Установите PostgreSQL 18.6, создайте БД `mir_jurnalov`.
2. Выполните `src/db/mir_chasov.sql` в pgAdmin.
3. Установите зависимости: `pip install PySide6 psycopg2-binary`.
4. Запустите: `python src/app/main.py`.
